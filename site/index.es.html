ResearchRabbit, para agentes de IA

Dale a tu agente el grafo de citas.

Un servidor MCP que expone el grafo de citas de ResearchRabbit como 22 herramientas en una sola URL — para que cualquier agente compatible con MCP (Claude Code, Cursor, Windsurf, VS Code) pueda buscar artículos, hacer crecer la frontera (trabajo similar / anterior / posterior), filtrar y clasificar candidatos, y abrir sesiones de ResearchRabbit en tu cuenta. Cada resultado lleva un DOI real, sacado directo de api.researchrabbit.ai — tu agente nunca inventa una cita.

¿Sin agente que configurar? Warren es un chat ya hecho sobre las mismas 22 herramientas — mismos DOIs, mismas sesiones, sin instalar nada. Está a un clic más abajo.

¿Qué es esto?

Una puerta de entrada al grafo de citas de ResearchRabbit para agentes de IA. Un servidor MCP expone 22 herramientas en una sola URL — tu agente las llama para buscar, hacer crecer y clasificar la literatura, y cada artículo vuelve con un DOI real sacado directo de api.researchrabbit.ai. Se acabaron los agentes que inventan citas.

🛡️

Nunca fabrica una cita

Cada título, autor, año, revista y DOI proviene del resultado de una herramienta en el mismo turno. Sin DOI, no hay recomendación. Una cita fabricada es lo peor que puede hacer — así que no lo hace.

🌱

Hace crecer la frontera

Trabajo similar (la red más amplia), trabajo anterior (fundamentos / referencias), trabajo posterior (citas que recibe, opcionalmente desde un año dado), o una expansión clasificada por consenso en una sola llamada.

📊

Clasifica por consenso

Cada candidato lleva seedHits (cuántos de tus semillas se conectan a él) y citationsPerYear (para que un artículo fuerte de 2024 le gane a uno cansado de 1998).

🔗

Te deriva a ResearchRabbit

Un enlace de sesión de ResearchRabbit en su propia línea, tocable en el móvil — un enlace profundo real app.researchrabbit.ai/search/… a tu cuenta, nunca una URL fabricada.

De la primera pregunta a la lista corta clasificada

Seis pasos que tu agente ejecuta — enmarcar, sembrar, expandir, filtrar, clasificar, derivar. Solo pregunta lo que necesita y nunca te hace repetir.

  1. Encuadrar

    Reformula tu pregunta en una línea y anota el ángulo que te interesa — población, resultado, mecanismo, enfoque de equidad, ventana temporal.

  2. Sembrar

    search_keyword sobre 1–3 formulaciones del tema. Muestra 3–5 semillas candidatas, cada una con DOI + citedBy, y te pide elegir 1–3 (o nombrar un artículo conocido).

  3. Expandir

    La dirección que coincide con tu pregunta: search_similar, search_earlier_work, search_later_work, o expand_frontier para una lista corta amplia en una sola llamada.

  4. Filtrar y clasificar

    screen_articles descarta artículos fuera de un umbral de año / tipo de documento / citas o los retractados; rank_candidates ordena la lista corta con una razón por elemento.

  5. Verificar

    Antes de respaldar un artículo, credibility_check cubre retractación, tipo de documento, revista, conteos e h-index del primer autor — con las salvedades integradas.

  6. Derivar

    Un enlace de ResearchRabbit en su propia línea, para que puedas tocarlo en el móvil y seguir visualmente en la app.

Arquitectura

Cuatro partes móviles, un camino de petición. Un agentflow para la conversación, un modelo de lenguaje para las decisiones, un servidor MCP para las herramientas y un gateway REST que habla con la API de ResearchRabbit (api.researchrabbit.ai) usando tu token de sesión.

  • Agente e interfaz de chat

    Flowise 3.1.2

    Un servicio Docker que aloja el Agentflow — un nodo Start hacia un nodo Agent. Sirve la ventana de chat en la esquina de esta página y orquesta cada turno.

  • Modelo de lenguaje

    Fireworks glm-5p2

    accounts/fireworks/models/glm-5p2 a temperatura 0.2, streaming activado, con allMessages como memoria para que toda la conversación permanezca en contexto. Tool-calling nativo.

  • Capa de herramientas

    Servidor MCP (22 herramientas)

    Node + Express con @modelcontextprotocol/sdk, hablando Streamable HTTP en POST /mcp. Sin estado: un mensaje JSON-RPC por petición. Las 22 herramientas están cableadas al agente.

  • Capa de datos

    Gateway REST → ResearchRabbit

    Un servicio Node + Express frente a la API de ResearchRabbit (api.researchrabbit.ai), autenticado con tu JWT sessionToken (enviado como Authorization: Bearer). Expone endpoints REST simples que las herramientas MCP llaman y mapea el grafo de citas de RR a una forma canónica de artículo con DOIs reales.

El camino de una sola pregunta

  1. 1

    Tú

    «Encuéntrame 5 artículos semilla sobre doseles arbóreas urbanas y equidad térmica, cada uno con un DOI.» entra en la ventana de chat.

  2. 2

    Agentflow de Flowise

    Flowise recibe el mensaje, añade el prompt de sistema de Warren y el historial allMessages, y pasa el turno al nodo Agent.

  3. 3

    LLM de Fireworks

    El modelo decide si necesita datos y, si es así, cuál de sus 22 herramientas MCP llamar y con qué argumentos.

  4. 4

    Servidor MCP

    La llamada a la herramienta llega por Streamable HTTP a POST /mcp y se despacha a la implementación de la herramienta correspondiente.

  5. 5

    Gateway REST → ResearchRabbit

    Esa herramienta llama al gateway, el único componente que puede hablar con api.researchrabbit.ai directamente (con tu token de sesión). Devuelve artículos reales con DOIs reales.

  6. ↩

    …y de vuelta por el mismo camino

    Gateway → servidor MCP → el modelo, que convierte el resultado bruto en una respuesta respaldada por DOIs y la transmite token a token a la ventana de chat.

Los tres servicios — Flowise, el servidor MCP y el gateway REST — están desplegados como servicios web de Render. El agentflow, el endpoint MCP y el endpoint de predicción son todos públicos; para obtener datos reales de ResearchRabbit conectas tu cuenta con tu sessionToken — vía el panel Conectar (web) o la cabecera MCP X-RR-Token (editor).

El agente como cliente de primera clase

Warren no es una web con un chat pegado encima — es una caja de herramientas que conduce un agente. Hay dos formas de entrar, y ambas corren contra tu cuenta de ResearchRabbit con el mismo sessionToken: apunta tu propio agente al servidor MCP, o habla con el chatbot de Warren aquí mismo. Consigue tu token primero y pulsa Más información en el cliente que elijas.

Cómo obtener tu sessionToken

ResearchRabbit guarda tu sesión iniciada como un JWT en el localStorage de la app. Copiarlo toma un minuto:

  1. Abre app.researchrabbit.ai e inicia sesión (email/contraseña o Google).
  2. Abre DevTools (F12) → Application → Local Storage → https://app.researchrabbit.ai. Haz clic en la clave tokens. El valor es un JSON como {"sessionToken":"eyJ…"} — copia solo la cadena sessionToken (el JWT largo eyJ…, no todo el JSON).
  3. Pégalo en la cabecera X-RR-Token de tu .mcp.json (agente/harness) o en el panel Conectar del chatbot Warren — ambos están a un clic de Más información en las tarjetas de abajo. Tu projectId se descubre automáticamente — no lo necesitas.

¿Qué es un token de sesión? Es una credencial bearer — quien la tenga puede actuar como tú en ResearchRabbit. Por eso se guarda solo en el gateway (no en la transcripción del chat, no en el repo) y por eso deberías desconectarte al terminar. Expira por sí solo; si Warren dice «sesión expirada», solo repite los pasos con un token nuevo.

Usa las mismas herramientas en Claude (y cualquier cliente MCP)

Las 22 herramientas que dan vida a Warren son un servidor MCP. No necesitas Flowise para usarlas — conecta el servidor directamente a Claude Code, Claude Desktop, Cursor, Windsurf o VS Code y obtienes las mismas herramientas de descubrimiento de literatura dentro de tu editor. Corren contra la API de ResearchRabbit (api.researchrabbit.ai), así que debes enviar tu JWT sessionToken como cabecera X-RR-Token en cada petición — ver cómo obtener tu sessionToken arriba y la Opción B de abajo.

El endpoint

Alojado (siempre activo): https://researchrabbit-mcp-server.onrender.com/mcp
Local (al ejecutar el repo): http://localhost:8822/mcp

Obligatorio — tu token de sesión: envía una cabecera en cada POST /mcp — X-RR-Token (tu JWT sessionToken del localStorage de app.researchrabbit.ai). El servidor lo reenvía al gateway, que llama a api.researchrabbit.ai como tú con Authorization: Bearer (y descubre automáticamente tu projectId). Sin ella las herramientas no pueden alcanzar ResearchRabbit.

Transporte: Streamable HTTP, sin estado. Una petición JSON-RPC por POST /mcp. GET /mcp devuelve 405; el descriptor vive en GET /. No se requiere handshake de initialize — solo envía tools/list o tools/call.

Opción A — Claude Code (un comando)

Registra el servidor con la CLI de Claude Code. La bandera --transport http es la parte clave — este es un servidor HTTP, no un subproceso stdio.

terminalbash
# registra el servidor MCP alojado (ámbito de proyecto por defecto)
claude mcp add --transport http researchrabbit https://researchrabbit-mcp-server.onrender.com/mcp

# o, cuando ejecutas el repo en local:
# claude mcp add --transport http researchrabbit http://localhost:8822/mcp

# verifica que se conectó
claude mcp list
claude mcp get researchrabbit

La CLI registra el servidor sin cabecera. Para usarlo debes editar luego el .mcp.json generado para añadir la cabecera X-RR-Token mostrada en la Opción B (claude mcp add no acepta cabeceras directamente). O sáltate la CLI y usa la Opción B desde el principio.

Opción B — archivo .mcp.json del proyecto (Claude Code, Cursor, Windsurf, VS Code)

Deja este archivo en la raíz de tu repo (o tu directorio personal). Es la forma portable y versionable de compartir el servidor con tu equipo — todo cliente compatible con MCP lee el mismo formato. El bloque headers de abajo lleva tu token de sesión de ResearchRabbit — es obligatorio, no opcional. Ver cómo obtener tu sessionToken.

.mcp.jsonjson
{
  "mcpServers": {
    "researchrabbit": {
      "url": "https://researchrabbit-mcp-server.onrender.com/mcp",
      "headers": {
        "X-RR-Token": "<tu JWT sessionToken>"
      }
    }
  }
}

La burbuja de chat de la esquina inferior derecha abre el chat en una pestaña nueva. Escribe una de estas para empezar. La primera respuesta puede tardar unos segundos mientras los servicios despiertan de un arranque en frío.

  • «Encuéntrame 3 artículos semilla sobre cobertura arbórea urbana y equidad térmica, cada uno con un DOI.»
  • «¿Cuáles son los artículos fundamentales detrás de Redlining and intra-urban heat?»
  • «¿Qué se ha publicado desde 2022 que cite Disproportionate exposure to urban heat island intensity?»
  • «Constrúyeme una preselección amplia sobre reverdecimiento urbano y equidad frente a la vulnerabilidad al calor — 10 artículos, ordenados por consenso.»
  • «Solo tengo un título: Trees Grow on Money. ¿Cuál es su DOI y está retractado?»
  • «Lista los artículos más citados de Carly Ziter con su h-index.»
  • «De estos candidatos, conserva solo las revisiones desde 2018 con 50+ citas, y descarta las retractadas.»
  • «Dame el BibTeX de los 5 artículos semilla que encontraste.»
  • «No tengo ni idea de por dónde empezar con la efectividad de la adaptación al cambio climático. Guíame y termina con un enlace que pueda abrir.»
