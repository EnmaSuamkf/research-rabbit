Warren · ResearchRabbit Copilot

A literature-discovery assistant — find, rank and organise papers, then hand off to ResearchRabbit.

Local stack

Three services run on localhost (Stage 1):

  • Gateway REST API — http://localhost:8821 (health)
  • MCP server (22 tools) — http://localhost:8822/mcp (descriptor)
  • Flowise — http://localhost:3000

Backend: OpenAlex (free, public metadata). RR-only features (sessions, collections, the app deep link) return a structured "not available" message on this backend.

Chat widget

The embedded Flowise chat widget loads below once an Agentflow is published. The chatflowid and apiHost are set in Stage 3 (§16.6); locally, point apiHost at http://localhost:3000.

The widget renders inside a <flowise-fullchatbot> Shadow DOM. Serve this file with npx serve site so the origin matches ALLOWED_ORIGINS.

Try it without Flowise

The MCP server is registered in Claude Code (claude mcp list) and answers research questions directly through the 22 tools — the fastest feedback loop and alternative app #1 (§12).
